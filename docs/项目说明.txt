校园网自动登录（Windows）项目说明

一、项目结构

1. CampusNetAutoLogin.ps1
   主程序，提供图形界面、断网检测、自动重登、主账号和备用账号切换。

2. 自动登录校园网.bat
   启动入口，双击即可打开程序。

3. docs\项目说明.txt
   当前说明文档。

二、主要功能

1. 断网检测
   程序会按设置的间隔检测网络是否真正可用。

2. 自动重登
   检测到断网后，会自动尝试使用主账号重新登录校园网。

3. 备用账号
   如果主账号多次登录后仍不能联网，会自动尝试备用账号。

4. 定时登录
   可以设置每隔一段时间主动登录一次。

5. 直连模式
   默认开启。程序会尽量绕过系统代理，使用 curl.exe --noproxy * 直连校园网认证地址。
   注意：如果 VPN 是全局虚拟网卡接管路由，仍需要在 VPN 软件里设置分流，程序本身无法强行绕过。

6. 开机启动
   可在界面勾选“开机启动”。

7. 密码显示/隐藏
   密码框右侧有小眼睛按钮，可单独切换主账号和备用账号密码是否可见。

三、使用方式

1. 双击“自动登录校园网.bat”。
2. 填写登录地址、检测地址、主账号、主账号密码。
3. 如有备用账号，也填写备用账号和密码。
4. 根据需要设置检测间隔、定时登录、直连模式和开机启动。
5. 点击“开始守护”。

四、关于检测地址和期望内容

检测地址用于判断当前网络是否真的可用。
程序会检查 HTTP 状态码、最终跳转地址、页面内容是否像认证门户。
如果填写了“期望内容”，程序还会要求返回内容中包含该文本。

五、关于账号密码安全

项目文件夹本身不保存明文账号密码。
账号密码配置保存在当前 Windows 用户目录：
%APPDATA%\CampusNetAutoLogin\config.json

密码使用当前 Windows 用户的 DPAPI 加密。
把项目文件夹发给别人时，不要把上面的 config.json 一起发出去。

六、常见问题

1. 登录请求返回 502 Bad Gateway
   可能是校园网认证服务器临时异常，也可能是 VPN 或代理影响了访问。
   可以开启“直连模式”，并尝试关闭 VPN 或在 VPN 软件中设置校园网地址直连。

2. 密码错误但 HTTP 200
   HTTP 200 只表示认证接口收到了请求，不代表登录成功。
   程序会继续检查返回内容，如果发现密码错误、认证失败、余额不足等信息，会判定为登录失败。

3. 发给别人会不会泄露账号密码
   只发送项目文件夹通常不会泄露账号密码。
   不要发送 %APPDATA%\CampusNetAutoLogin\config.json，也不要发送已经显示密码的截图。
