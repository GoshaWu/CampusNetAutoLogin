# 校园网自动登录

一个 Windows 桌面小工具，用于在校园网断线、认证失效或网络被门户页拦截时自动重新登录。支持主账号、备用账号、定时登录、直连模式和开机启动。

## 下载后怎么用

1. 点击 GitHub 页面右侧或顶部的 `Code`。
2. 选择 `Download ZIP`。
3. 解压下载的压缩包。
4. 双击 `自动登录校园网.bat`。
5. 填写校园网账号、密码和备用账号。
6. 点击 `开始守护`。

不需要安装程序，也不需要手动修改 PowerShell 执行策略。启动脚本会自动以当前用户权限运行主程序。

## 主要功能

- 断网检测：定时检测当前网络是否真的可用。
- 自动重登：检测到断网或认证页拦截后自动登录校园网。
- 备用账号：主账号失败后自动切换备用账号。
- 定时登录：可按固定间隔主动发起登录。
- 直连模式：默认绕过系统代理，尽量避免 VPN/代理影响校园网认证。
- 密码可见性：密码框右侧有小眼睛按钮，可单独显示或隐藏密码。
- 开机启动：可在界面中启用。
- 自动保存：账号和设置会自动保存，下次打开无需重新填写。

## 系统要求

- Windows 10 或 Windows 11
- Windows PowerShell 5.1 或更高版本
- 系统自带 `curl.exe`

大多数 Windows 10/11 系统都已经满足这些条件。

## 文件说明

- `docs/项目说明.txt`：纯文本说明文档。

## 账号和密码安全吗

项目文件夹本身不会保存明文账号密码。

程序配置保存在当前 Windows 用户目录：

```text
%APPDATA%\CampusNetAutoLogin\config.json
```

密码使用 Windows 当前用户的 DPAPI 加密。把这个 GitHub 项目发给别人，通常不会泄露你的账号密码。不要把自己的 `config.json` 一起发出去，也不要发送已经显示密码的截图。

## 关于直连模式和 VPN

如果 VPN 只是设置了系统代理，直连模式通常可以绕过代理访问校园网认证地址。

如果 VPN 是全局虚拟网卡接管路由，程序本身无法强行绕过 VPN。需要在 VPN 客户端里设置分流，或给校园网认证地址添加本地直连路由。

## 常见问题

### 登录返回 HTTP 200，但实际上没登录成功

HTTP 200 只表示认证接口收到了请求，不代表账号密码正确。程序会继续检查返回内容，如果发现密码错误、认证失败、余额不足、欠费等信息，会判定为登录失败并尝试备用账号。

### 出现 502 Bad Gateway

这通常表示校园网认证网关临时不可用，或者 VPN/代理影响了访问。可以尝试：

1. 开启 `直连模式`。
2. 临时关闭 VPN 后再试。
3. 在 VPN 软件里把校园网认证地址加入直连/分流规则。
4. 稍后再试，等待校园网认证服务恢复。

### 运行时闪退或打不开

请确认你是双击 `自动登录校园网.bat`，不要直接双击 `.ps1` 文件。
